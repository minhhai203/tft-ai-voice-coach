# Contract v1 — chuẩn ghép module cho coding agents

Đây là đặc tả cần implement, **chưa phải API đang tồn tại**. Path đều tương đối với repo root trên cả macOS/Windows. Thay contract phải có coordinator sửa tài liệu này và contract tests trước; agent không tự đoán field khác. Baseline JS CommonJS khi Node test; browser dùng IIFE namespace `window.TftCoach`, không require SDK trong browser. Dùng dependency injection cho clock, timer, random ID, Overwolf API, fetch, Audio; không thêm bundler/framework.

## 1. Runtime và trạng thái

- `schemaVersion: 1`; `runtimeMode: 'synthetic'|'manual'|'overwolf'`; fixture không được đóng nhãn live.
- Feature flags mặc định: `liveAdaptive:false`, `inGameVoice:false`, `jev:false`, `capture:false` cho tới khi capability gate phù hợp được ghi nhận. Static HUD được phép chỉ nhận plan snapshot; không nhận recommendation từ live state.
- App lifecycle: `idle -> detecting -> active -> finalizing -> reviewReady -> idle`; detecting có thể trở về idle vì LOL/unknown. `sessionEpoch` tăng khi start/stop/new match; `reviewGeneration` tăng khi tạo/revise review, new match, mute hoặc dispose.
- Một background controller sở hữu adapter, session manager, voice engine. Desktop/overlay chỉ gửi intent, không mở listener/synth riêng. Browser load background entry guarded: import trong Node không tạo app.

## 2. Event, state, evidence

```js
// Local envelope; receivedAt là clock monotonic trong một process, không so giữa restart.
{ schemaVersion:1, sessionId:'local-id', epoch:3, seq:12,
  receivedAt:4000, source:'gep', kind:'patch',
  patch:{gold:29, health:82, stage:'2-1', level:5} }
// source: gep|manual|synthetic. kind: patch|matchEnd|summary.
// seq tăng do adapter, không giả là sequence của game server.
// Mỗi field chỉ có khi source thật sự gửi; absent khác null/empty.
```

`GameState = {schemaVersion, sessionId, epoch, revision, status, patchVersion:null|string, gameMode:null|'TFT', fields:{gold,health,stage,level}, quality, warnings}`. Mỗi field là `{value:null|number|string, source:null|'gep'|'manual'|'synthetic', observedAt:null|number, seq:null|number}`. `quality:'unknown'|'partial'|'verified'` chỉ diễn tả completeness/schema của dữ liệu, không đảm bảo chiến thuật đúng. Gold integer>=0, health integer 0..100, level integer 1..20, stage `/^\d+-\d+$/`; khác định dạng reject field + warning. Không mặc định HP100/gold0/stage1-1; hp0 là known. Giới hạn chỉ là validation v1, P1 xác minh theo mode/patch; không âm thầm clamp.

`normalizeGepUpdate(raw, context) -> {patch, warnings}`: chỉ nhận `raw.info` object hoặc JSON object string đã parse an toàn. `me.gold`, `me.health` số dạng string; `me.xp` JSON string/object lấy level; `match_info.round_type` JSON string/object lấy stage. Không giả streak/round outcome. `match_info.game_mode` dùng xác nhận TFT; pseudo_match_id chỉ metadata Overwolf, không Riot matchId. MVP không nhận augments/opponent/pool/shop/board/items; các module này hoãn. Parse invalid một field không làm mất các field hợp lệ cùng payload.

`reduceState(previous,envelope) -> next`: thuần, không mutate; reject epoch/session sai, seq<=last applied; increment revision một lần/envelope. Merge toàn payload trước bất kỳ subscriber nào. Lưu ledger sanitized cho mỗi field update chấp nhận: `{id:'sessionId:seq:field',sessionId,seq,field,value,source,observedAt}`. Không lưu raw tên người chơi/summoner/token. `observed` không đồng nghĩa người chơi đã chủ động chọn. `planned` và user annotation không trộn observed.

`createOverwolfAdapter({ow,clock,timers,onEnvelope,onStatus}) -> {start(),stop()}`: start/stop idempotent; callback refs cố định. Shared class5426 chỉ cho bootstrap `match_info`; chỉ dùng metadata game_mode/lifecycle khi chưa TFT. Success của `setRequiredFeatures` là `success` và `supportedFeatures`; không dùng `status`. Retry các failure tối đa 3 lần sau lần đầu, delay 250/1000/3000ms, hủy khi stop/epoch đổi. TFT confirmed mới mở subscription own fields được gate cho phép. Unknown/LOL không ingest own data. Reconnect/session id đổi phải reset trước capture tiếp.

`getInfo` trả `{success,res}`: adapter bọc `{info:res}` và cùng allowlist. Snapshot request chụp revision từng field; khi trả chỉ bổ sung field đang unknown và chưa đổi từ lúc request. Không overwrite event mới bằng snapshot; không có server ordering thì ghi warning, không suy đoán. Lấy snapshot sau feature registration và TFT confirmation; snapshotbootstrap metadata là ngoại lệ chỉ đọc game_mode. Không có matchId vẫn được session local, không merge hai trận theo pseudo ID mù quáng.

## 3. Kết thúc trận và review

`createSessionManager({clock,newId})` cung cấp `start({source,patchVersion,planSnapshot})`, `ingest(envelope)`, `finish({reason})`, `getLive()`, `getCompleted(sessionId)`, `reviseSummary(sessionId,summary)`.

- finish transaction: freeze copy state+ledger+plan -> `CompletedSession` -> clear live. Duplicate end trả cùng completed object/revision; không voice lần hai. Missing normal end do crash/stop => `completion:'interrupted'`; chỉ review phần evidence có thật.
- `CompletedSession={schemaVersion:1,id,revision:1,source,patchVersion,completion:'ended'|'interrupted'|'imported',startedAt,endedAt,planSnapshot,finalState,evidence:[],summary:null|object}`. Wall clock ISO cho export started/ended; monotonic observations chỉ nội bộ phiên. summary chỉ whitelist placement1..8 và game duration nếu có source thật; không đòi GEP chắc chắn cung cấp.
- Summary đến muộn tạo immutable revision2, không mutate revision1. App tăng reviewGeneration và hủy audio của review cũ trước replace. New match giữ completed để đọc nhưng dừng review/audio tự động của phiên cũ.
- Ledger cap 5,000 rows/session: khi vượt, không silent truncate rồi nói đủ dữ liệu; đánh `warnings:['evidence_truncated']` và chỉ review phạm vi còn chứng cứ. Giữ tối đa 5 completed sessions trong RAM. Không database baseline. Người dùng chủ động export/import JSON sanitized, tối đa 2MiB/5,000 rows; validator chặn unknown schema/oversize/field không hợp lệ; ignore unknown field không thực thi nội dung.

## 4. Catalog, kế hoạch và coaching

`CatalogPack={schemaVersion:1,id,patchVersion,mode:'synthetic'|'verified',provenance:{url,revision,checkedAt},rules:{interestThresholds:[10,20,30,40,50]},champions:[],items:[]}`. Fixture synthetic không nguồn game thật phải ghi `url:null, revision:'fixture'`; pack verified cần nguồn/cách sử dụng đã kiểm tra. Không ship YAML14.23 hoặc tự nhận patch hiện tại. Missing/mismatch pack => không nhận xét rule-dependent. Không cần database/cache/vector store.

`validateCatalog(input)->{ok,errors}`; `nextInterestInfo(gold,thresholds)->{nextThreshold:null|number,gap:null|number}` là utility arithmetic; thresholds strictly increasing integers; gold>=max => null/null. Đây không phải lệnh save/roll/level, không cộng economy suy diễn.

`createPlan({focus,text,patchVersion}, {clock,newId}) -> PlanSnapshot`: focus enum `economy|items|tempo|custom`, user text plain <=300chars, immutable `{id,createdAt,focus,text,patchVersion}`. Pregame tự người dùng chọn; khi active chỉ đọc bản snapshot. Không tải meta gợi ý tự động.

`buildReview(completed, catalog) -> Review` thuần:
```js
{schemaVersion:1, sessionId:'s1', sessionRevision:1,
 status:'ready', // ready|insufficient_evidence|patch_mismatch
 observations:[{id:'o1', reasonCode:'ECONOMY_SNAPSHOT',
   text:'Ở mốc 2-1, dữ liệu ghi nhận 29 vàng.',
   evidenceIds:['s1:12:gold','s1:12:stage'], kind:'observation'}],
 limitations:[], source:'rules'}
```
Tối đa 3 observations, 1 câu/observation <=180chars, không score/winrate/counterfactual nguyên nhân. Cùng mốc chỉ ghép khi cùng envelope hoặc chứng minh snapshot fields vẫn hợp lệ; không gắn stage mới với vàng cũ. Missing evidence => abstain; không lấy planned action làm observed action. “Nhắc ít nhưng đúng”: chỉ người dùng bấm đọc review, không auto play hàng loạt. Tự phát sau trận là tùy chọn tương lai, không baseline.

## 5. Voice contract và local service

`createVoiceEngine({createAudio,clock,timers,service,onStatus}) -> {enqueue(job), mute(), unmute(), cancelScope(scopeId), dispose()}`. Job `{id,dedupeKey,scopeId,reviewGeneration,text,createdAt,expiresAt}`; scopeId là `sessionId:revision`. Mỗi queue tối đa 3 pending +1 active, drop oldest pending khi đầy; FIFO, dedupe cùng key trong scope; TTL15s trước phát. Chỉ một Audio phát; await ended/error trước next. Muted enqueue bị reject; unmute không phát lại queue cũ. Audio.pause + currentTime=0 + URL.revokeObjectURL + abort fetch khi mute/cancel/dispose; tăng generation, bỏ mọi late body/play promise. Mute acceptance <=200ms đo trên Windows; chưa phải số đo đã đạt. Audio lỗi không tự chuyển Web Speech giọng khác; trả status cho desktop.

Cache bounded tối đa 50 WAV/20MiB RAM, key exact text+voiceArtifactHash+settingsVersion; không dùng cache cũ khi model đổi. Cache hit vẫn check generation/TTL/muted. Max WAV8MiB, text<=300 Unicode codepoints, body<=8KiB; toàn bộ fetch/body deadline5s (khác thời gian playback), một retry tự động: **không**. Server synth busy =>503, UI trạng thái; queue nằm client, server chỉ một slot active, không queue vô hạn. Abort fetch không chứng minh ORT compute ngừng.

Python service stdlib HTTP wrapper, `127.0.0.1:port` do launcher chọn; CPU-only `PiperVoice.load(...,use_cuda=False)` và model fixed, synth WAV writer. Không Flask stock server/download routes. `GET /health`: `{app:'tft-voice',protocol:1,instanceId,ready:boolean}` không text/path. Identity proof: launcher tạo random secret và instanceId, bootstrap cấu hình truyền qua file local ACL; `GET /health?nonce=<random>` thêm HMAC-SHA256(secret, instanceId+':'+nonce), app verify với Web Crypto trước gửi bearer/text. Không gửi secret trong health URL. Private process ownership record giữ PID+creationTime+executable+instanceId; không reuse chỉ vì health string giống.

`POST /v1/synthesize`: bearer session secret, exact Origin allowlist đo từ Overwolf desktop/background (không wildcard/null), content-type application/json; `{requestId,text}` only. Success200 `audio/wav`, Cache-Control:no-store; header X-Request-Id echo. Errors `{error:{code,requestId}}`, codes INVALID_REQUEST400, UNAUTHORIZED401, ORIGIN_DENIED403, TOO_LARGE413, BUSY503, NOT_READY503, SYNTHESIS_FAILED500. OPTIONS preflight chỉ exact allowlist, headers Authorization/Content-Type, methods GET/POST; không reflect arbitrary Origin. Origin missing chỉ cho launcher health, không synth. Unauthorized/bodylimit kiểm trước inference. Tokens/session file không vào source/log. Không endpoint nhận path/model/URL. Nếu không xác minh Origin/bootstrap trên Windows: TTS disabled, text review vẫn chạy; không hạ auth cho demo.

## 6. UI message protocol

Overwolf `sendMessage(windowId, messageId, content, callback)`; messageId `'TFT_COACH_V1'`, content là object contract, **không JSON.parse vô điều kiện**. Adapter test object/string transport wrapper explicit once; reject invalid schema/types. Payload `{schemaVersion:1,type,requestId,sessionId:null|string,payload}`. UI intents: GET_VIEW, SAVE_PLAN, REQUEST_REVIEW, PLAY_REVIEW, MUTE, UNMUTE, IMPORT_SESSION, EXPORT_SESSION. Background updates VIEW_STATE/VOICE_STATUS/ERROR; view `{lifecycle,planSnapshot,review,voiceStatus,capabilities}`. Overlay receives only `{planSnapshot,voiceStatus}` static; update settings outside active only. Callback errors surfaced; text via textContent, không innerHTML từ import/API. Background owns all actions and request dedupe. Xem §9: intent dùng getMainWindow facade, sendMessage chỉ cập nhật view, không giả định sender authentication.

## 9. Integration clarifications (normative)

- `clock={now:()=>monotonicMs,isoNow:()=>ISO8601}`; `newId:()=>string`; timers={setTimeout,clearTimeout}. `createPlan` nhận DI argument thứ hai. Production clock wraps performance.now/Date; tests fake clock.
- Session manager là single identity owner: `start(...)` trả `{sessionId,epoch}`; gọi lại khi session active trả cùng context, chỉ `finish` rồi start mới tạo epoch mới. `getLive()` trả GameState|null; `ingest` trả `{accepted,state,warnings}`; `finish` trả CompletedSession|null; `reviseSummary` trả new CompletedSession hoặc unchanged nếu duplicate/invalid. Manager giữ ledger, reducer không giữ ledger. State thêm `lastSeq:0`, updates only accepted seq.
- Adapter factory bổ sung `getSessionContext:()=>({sessionId,epoch}|null)` và `capabilities:()=>({metadataAllowed:boolean,capture:boolean})`. `onStatus({type:'detecting'|'tftConfirmed'|'otherGame'|'unavailable'|'stopped',reason:null|string})`. Background xử lý tftConfirmed đồng bộ tạo manager session, rồi adapter mới lấy context để emit; capture false => không đăng ký own fields/emit patch. Adapter dùng context mới reset local seq, callback capture epoch khi bắt đầu async; callback muộn không relabel sang epoch mới. End => emit matchEnd của context hiện hành; background finish trước clearing context. stop/dispose phải vô hiệu mọi pending callback dù không có session mới.
- Manager ledger tạo từ **accepted validated** changes; observed fields lặp giá trị vẫn có seq chứng cứ mới để tái dựng đồng thời. Bổ sung `importSession(input)->{ok,session:null|CompletedSession,errors:[]}` và `exportSession(completed)->string` tại `src/core/session-codec.js` P2; không import raw executable/html/provider fields. Import source đổi `manual`, giữ original source dưới annotation sanitized nếu cần; không gán live.
- Bootstrap P4 `src/voice/serviceClient.js`: đọc `overwolf.io.paths.localAppData + '/TftVoiceCoach/runtime/session.json'` qua `overwolf.io.readTextFile(path,{encoding:overwolf.io.enums.encoding.UTF8,maxBytesToRead:8193,offset:0},callback)`; require success/content/info.eof và <=8KiB, validate schema, chưa có file thì TTS unavailable. Nguồn: [IO API](https://dev.overwolf.com/ow-native/reference/io/ow-io/), [paths](https://dev.overwolf.com/ow-native/reference/io/paths/). Nếu callback eof semantics/version khác phải cập nhật contract+fixture, không đọc file vô hạn.
- Bootstrap `{protocol:1,host:'127.0.0.1',port,instanceId,secretHex,allowedOrigins:[],createdAt,voiceArtifactHash}`; secretHex 32 random bytes hex64, nonce32 random bytes hex64, HMAC hex64. File ACL current Windows user, không Git/log/URL; atomic write+rename. TTS service chỉ đọc đường dẫn cố định/launcher-config path, commandline chỉ path không token. Chỉ trust loopback host và port1..65535; unsupported protocol reject. Browser HMAC Web Crypto; absence reject. Exact origin được lấy từ extension runtime đã biết, cấu hình launcher allowlist explicit; health/OPTIONS phản hồi CORS exact origin khi có, không wildcard; expose X-Request-Id. Health kiểm instanceId và HMAC trước synth; bootstrap file đọc lại khi serviceUnavailable/restart bằng user retry, không background token polling vô hạn.
